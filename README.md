# Expo save image demo

A React native app with expo for Android app. The app can select image from phone, and save to FileSystem (expo-file-system), also presents a gallery to list saved images.

## How to Run

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```
